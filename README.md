SecureEdge - Real-Time Financial Transaction Monitoring System
Overview
SecureEdge is a cutting-edge real-time financial transaction monitoring system designed to detect fraudulent activities. It uses a Machine Learning model to analyze transactions instantly, running on the edge devices (such as ATMs, mobile apps, or smart banking systems). This project optimizes the interaction between the machine learning model and the Operating System (OS) to ensure smooth, real-time fraud detection with minimal system resource usage.

Key Features
Real-Time Fraud Detection: Detects fraudulent transactions as they happen.

Machine Learning: Uses a Random Forest model trained on transaction data.

Operating System Interaction: Optimizes performance with multithreading, process prioritization, and resource monitoring.

Secure Logging: Stores transaction details securely, with encryption or restricted access.

Edge Computing: Designed to run on edge devices for fast decision-making.
